Console with SampleBoot

SampleBoot is a boot menu for the MPC Sample. At power-on you choose which system starts: the stock MPC app, Console, or another custom system, all from one SD card. This page shows how to put Console on a SampleBoot card.

Not yet tested on a device. This follows SampleBoot's own documentation for systems laid out like Console, but it hasn't been confirmed on a real Sample. If you try it, please tell us how it went.

What you need
  • An MPC Sample on firmware 1.3.0, the version SampleBoot supports.
  • An SD card and a computer to copy files.
  • The Console zip (unzipped) and SampleBoot.
Steps

  1. Set up SampleBoot

    Follow SampleBoot's own instructions: copy its autorun folder to the top level of the card. If the card already has Console's autorun folder, move it out of the way first.

  2. Add Console's folder

    Copy the Console folder from the Console zip to the top level of the card, as usual. Don't put it inside another folder.

  3. Add Console's autorun folder as a system

    Copy Console's autorun folder into autorun/mods/ and rename it Console. That name is what appears in SampleBoot's menu.

  4. Add the marker file

    Inside autorun/mods/Console/, create an empty file called sampleboot.inplace. It tells SampleBoot that Console expects its own folder to sit at the top level of the card, which is how Console is laid out.

  5. Start the Sample

    Put the card in and switch on. Pick Console in SampleBoot's menu. Console's own start menu then appears as usual (PAD 1 for Console, PAD 2 for the stock MPC app).

The finished card
SD card
├─ autorun/                    SampleBoot
│  ├─ autorun.sh, autorun.json, autorun.check, sampleboot/
│  └─ mods/
│     └─ Console/              Console's own autorun folder, renamed
│        ├─ autorun.sh, autorun.json, dev-ssh.sh
│        └─ sampleboot.inplace   an empty file
└─ Console/                     Console's folder, at the top level
Good to know
  • Updating Console. Replace the Console folder at the top level, and Console's autorun folder inside mods/Console. If a replace removes sampleboot.inplace, add it again.
  • Your songs. They stay in the ConsoleData folder on the card, which an update never touches.
  • If something goes wrong. SampleBoot starts the stock app if a system doesn't start within 60 seconds. To bypass SampleBoot entirely, take the card out and rename its autorun folder to autorun-off. SampleBoot writes last-boot.log, and Console writes Console/install-status.txt, to help find the cause.
